The Blue Book

Document Data Schema

Version: 0.3

------------------------------------------------------------------------

1. Purpose

This document defines how The Blue Book stores, organizes, and processes
writing documents.

The Blue Book is a structured writing environment.

Documents are not stored as plain text.

Each paragraph is stored as a structured block with:

-   Content
-   Type
-   Language
-   Formatting rules
-   Export behavior
-   Metadata

The user manually defines structure.

The system does not automatically detect:

-   Scenes
-   Characters
-   Dialogue
-   Story structure

------------------------------------------------------------------------

2. Core Document Model

A document consists of ordered blocks.

Structure:

Document

Blocks

Block Type + Content + Metadata

Example:

{ document_title: “Chengpu Battle”,

blocks:[ { type:“scene_heading”, content:“INT. CAMP - NIGHT” },

    {
      type:"action",
      content:"The wind moves across the battlefield."
    },

    {
      type:"character",
      content:"JIN WEN GONG"
    },

    {
      type:"dialogue",
      content:"We cannot retreat."
    }

] }

------------------------------------------------------------------------

5. Screenplay Format System

The Blue Book supports professional screenplay formats.

The format rules are separated from the content.

------------------------------------------------------------------------

5.1 English Screenplay Format

Based on standard Hollywood screenplay conventions.

Block Types

Scene Heading

Type:

scene_heading

Example:

INT. OLD HOUSE - NIGHT

Formatting:

-   Uppercase
-   Left aligned
-   Scene spacing before and after

------------------------------------------------------------------------

Action

Type:

action

Example:

John enters the room.

Formatting:

-   Left aligned
-   Normal paragraph

------------------------------------------------------------------------

Character

Type:

character

Example:

JOHN

Formatting:

-   Uppercase
-   Center aligned

------------------------------------------------------------------------

Dialogue

Type:

dialogue

Example:

I never wanted this.

Formatting:

-   Narrow column
-   Indented from both sides

------------------------------------------------------------------------

Parenthetical

Type:

parenthetical

Example:

(whispering)

Formatting:

-   Centered under character
-   Smaller indentation

------------------------------------------------------------------------

Transition

Type:

transition

Example:

CUT TO:

Formatting:

-   Right aligned
-   Uppercase

------------------------------------------------------------------------

5.2 Chinese Screenplay Format

Chinese screenplay format.

Block Types:

场景

Type:

scene_heading_cn

Example:

内景 陶丘大营 夜

Formatting:

-   Left aligned
-   Scene identifier

------------------------------------------------------------------------

动作

Type:

action_cn

Example:

夜色压境，晋军营火如星。

Formatting:

-   Standard paragraph

------------------------------------------------------------------------

人物

Type:

character_cn

Example:

晋文公

Formatting:

-   Center aligned

------------------------------------------------------------------------

对白

Type:

dialogue_cn

Example:

退避三舍，并非退让。

Formatting:

-   Centered character dialogue format

------------------------------------------------------------------------

12. Design Principle

The Blue Book does not interpret writing.

The writer defines structure.

The application maintains:

-   Accuracy
-   Consistency
-   Formatting quality

Fonts for screenplay PDF export

Latin (required for English):
- CourierPrime-Regular.ttf
- CourierPrime-Bold.ttf
- CourierPrime-Italic.ttf
- CourierPrime-BoldItalic.ttf

CJK (required for Chinese / mixed scripts):
- NotoSansSC-Regular.otf  (preferred)
  or NotoSansSC-Regular.ttf
  or SourceHanSansSC-Regular.otf

If a file is missing locally, export tries a CDN fallback.
For reliable offline Chinese export, place NotoSansSC-Regular.otf here.

Noto Sans SC (OFL): https://github.com/googlefonts/noto-cjk
Courier Prime (OFL): https://github.com/quoteunquoteapps/CourierPrime
